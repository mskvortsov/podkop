Podkop OpenWrt package feed

Architecture-independent Podkop APK packages for OpenWrt 25.12.

OpenWrt 25.12 APK feed (.apk)

Install on OpenWrt 25.12

mkdir -p /etc/apk/keys /etc/apk/repositories.d
wget -O /etc/apk/keys/podkop-feed.pem "https://mskvortsov.github.io/podkop/keys/podkop-feed.pem"
echo "https://mskvortsov.github.io/podkop/apk/packages.adb" >> /etc/apk/repositories.d/customfeeds.list
apk update
apk add podkop luci-app-podkop luci-i18n-podkop-ru

Packages are rebuilt by the Podkop release workflow and published from GitHub Releases.
